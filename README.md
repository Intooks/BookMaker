# BookMaker



Оффлайн-приложение для написания книг. Рабочая версия: **https://usbashka.ru/bookmaker/**.

<img width="981" height="636" alt="image" src="https://github.com/user-attachments/assets/9c16c290-cd7d-4057-a89f-4637eb0e16cd" />
Древо частей и глав, редактор текста и расширенного Markdown, компактная вики персонажей и локаций, вставка с форматированием, метаданные и обложка книги. Книги сохраняются в браузере, есть история версий и резервные копии. Приложение устанавливается как PWA и работает без сети после первого открытия.

Экспорт: DOCX, EPUB 3, Markdown, JSON и главы для переноса на Фанфикс/Фикбук. Импорт: JSON, Markdown, TXT, HTML, FB2, EPUB, ZIP. Синхронизация с GitHub выполняется напрямую из браузера с пользовательским токеном.

## Запуск

Готовые файлы уже находятся в `web/bookmaker/`. Их можно разместить на любом статическом HTTPS-хостинге по пути `/bookmaker/`.

Для локального запуска из корня репозитория:

```sh
python -m http.server 8000 --directory web
```

Откройте http://localhost:8000/bookmaker/. PWA работает на HTTPS и localhost; открытие HTML через `file://` не поддерживает service worker.

## Разработка

Нужен Node.js 22 или новее:

```sh
npm --prefix bookmaker ci
npm --prefix bookmaker test
npm --prefix bookmaker run build
```

Исходники находятся в `bookmaker/src/`, тесты — в `bookmaker/tests/`. Сборка обновляет `web/bookmaker/`, версии JS/CSS и предварительный кэш PWA. Серверная логика и CDN не требуются.

При доступной сети приложение проверяет свежую оболочку. Обновление service worker сохраняет текущую книгу перед перезагрузкой; IndexedDB с книгами не очищается.

Подробности форматов, настройки GitHub, ограничения экспорта, проверки и происхождение фона: [bookmaker/README.md](bookmaker/README.md). Существующая лицензия репозитория сохранена в [LICENSE](LICENSE); лицензии сторонних JS-библиотек и шрифта находятся рядом с готовыми файлами.
