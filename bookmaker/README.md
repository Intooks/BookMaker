# BookMaker

Оффлайн-редактор книг: https://usbashka.ru/bookmaker/.

Статическое приложение находится в `web/bookmaker/`; FastAPI только выдаёт файлы. Главная страница сайта и её GitHub-токен не используются редактором.

Книги и история хранятся в IndexedDB. Первое открытие создаёт демонстрационную книгу; новая пустая книга доступна в «Мои книги». Корень — книга, ниже части и главы; главы можно перенести в часть через настройки или перетаскиванием. Вики имеет произвольные категории и ссылки `[[Название|Подпись]]`. При конфликте вкладок редактор сохраняет свою версию отдельной книгой.

Текст хранится в расширенном Markdown: GFM, `<u>`, `<sub>`, `<sup>`, `<center>`, `<right>`, `<note>`, `<empty-line>`. HTML очищается DOMPurify. Форматированная вставка переносит жирный, курсив, подчёркивание, списки, заголовки и выравнивание. Режим «Текст» преобразует HTML в Markdown, «Markdown» позволяет напрямую редактировать исходник.

## Форматы

- JSON BookMaker сохраняет структуру, метаданные, текст, вики и обложку. История версий и параметры подключения к GitHub остаются локальными.
- Импорт: JSON, Markdown, TXT, HTML, FB2, EPUB, ZIP с главами или резервной копией. Файлы до 50 МБ, распакованный архив до 100 МБ. В HTML распознаются блоки глав или заголовки h2, в EPUB — порядок spine, в FB2 — основные секции body. Изображения глав не встраиваются в экспорт; обложка поддерживается отдельно.
- Фанфикс: ZIP с отдельными TXT-главами в формате тегов fanfics.me, шапкой и JSON. Теги проверены по [официальной справке](https://fanfics.me/html?article=help_3). Поддерживаются `<b>`, `<i>`, `<u>`, `<s>`, `<center>`, `<right>`, `<note>`, `<empty-line>`, разделители сцен. Файлы надо перенести в редактор сайта; это не внутренний архив базы Фанфикса и не автоматическая публикация. Скачанные с Фанфикса FB2/EPUB/HTML импортируются общими импортёрами.
- Фикбук: ZIP с TXT-главами и квадратными тегами оформления. Сноски преобразуются в скобки. Прямого API публикации и проверки в авторизованном редакторе Фикбука нет: нужно проверить предпросмотр и завершить публикацию на сайте.
- DOCX: OOXML, A4, выбор шрифта, размера, полей, интервала, разрыва страниц и включения вики. Сноски выведены в скобках курсивом. Списки сохраняются; нумерованные списки экспортируются отдельными абзацами.
- EPUB 3: обязательный mimetype первым без сжатия, container.xml, OPF, XHTML, nav, обложка PNG, метаданные, сноски EPUB. Настраиваются шрифт, размер, интервал, красная строка, выравнивание, направление чтения, идентификатор, оглавление и включение вики. Системные шрифты не встраиваются. Проверены структура ZIP и XML; отдельный EPUBCheck не запускался.

## GitHub

Подключение работает напрямую через [GitHub REST API](https://docs.github.com/en/rest/git), серверная логика и OAuth-секрет не нужны. Пользователь вводит fine-grained PAT с Contents read/write для выбранного репозитория. Токен хранится только в памяти вкладки; в IndexedDB сохраняются репозиторий, ветка, папка и последний SHA. Исходный репозиторий должен иметь существующую ветку.

Одна папка книги содержит `bookmaker.json` и отдельные Markdown-файлы глав/вики. JSON задаёт состав, порядок и метаданные, содержимое известных Markdown-файлов подхватывается при загрузке; новые страницы нужно добавлять в BookMaker. Отправка создаёт blobs/tree/commit и обновляет ref без force. Изменение ветки блокирует отправку до загрузки актуальной книги. До загрузки сохраняется локальная история. Реальная запись в пользовательский репозиторий требует его токена; протокол проверен тестовыми ответами GitHub.

## Разработка

```powershell
cd bookmaker
npm ci
npm run build
npm test
```

Сборка создаёт самостоятельный JS без CDN и версию кэша из хешей ресурсов. Node.js нужен только разработчику. PWA установится из меню браузера; при поддержке beforeinstallprompt появляется кнопка «Установить». Все ресурсы, включая шрифт и фон, кэшируются service worker. При доступной сети HTML проверяется заново; версии JS и CSS закреплены в URL. Новая версия service worker активируется без ожидания закрытия вкладок; редактор сохраняет текущую книгу перед автоматической перезагрузкой. Оффлайн открывается последняя сохранённая оболочка. HTTPS или localhost обязателен для PWA.

`qa.cjs` проверяет браузер через установленный Playwright и Edge: редактирование, сохранение, восстановление последней главы, вики, форматированную вставку, шесть экспортов, импорт JSON, отключение сети, перезагрузку и сохранение оффлайн, ширины 390/768/1200. Для этого сценария нужны Playwright и установленный Edge; путь к внешнему модулю можно задать в `BOOKMAKER_PLAYWRIGHT`, адрес приложения — в `BOOKMAKER_URL`. Результаты сохраняются в игнорируемом `test-output/`.
